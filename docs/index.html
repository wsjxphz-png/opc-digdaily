打分怎么来的

不是问 AI「这条值几分」，而是「AI 只做观察，公式做判断」：AI 只回答一组能从原文看出来的事实型小问题（每个 1–5 分，每档有明确定义），加权公式写死在代码里。框架取自 Josh Kaufman《The Personal MBA》的十项经济性评估与独立创业圈的 BB Score，按「完全不会写代码的人」重新配了权重。此外还有一票压制规则：需要写代码最高 3 分、疑似卖课卖铲子最高 3 分、没写清客户从哪来最高 6 分。
