## 先说人话：这玩意儿是干嘛的

你大概看过不少"副业课""一人公司训练营"。它们大多有个隐藏前提：**你得先会写代码、先搭爬虫、先搞自动化**。

可现实中想搞副业的人，十个里有八个是文科生、是上班族、是根本不想碰键盘敲程序的人。那些课对他们来说，门槛高得离谱，学完还是不会干。

这个系统就是给这类人做的：**找案例、读内容、拆解、推送，全自动**。你唯一要做的，就是每天打开飞书，看今天又挖到了谁、人家是怎么赚钱的。不用装任何软件，不用懂一行代码。

## 为什么这份情报"值得抄"（重点）

市面上的"赚钱情报"大多有一个通病——**它们自己就是卖铲子的**。

> 19 世纪美国淘金热，真正稳赚的不是淘金的，是**卖铲子给淘金客**的人。今天很多"副业导师""一人公司教练"，就是卖铲子的：他们不靠自己的产品赚钱，靠"教你怎么做一人公司"收学费。

问题在哪？**模仿卖铲子的人，你学到的只是"怎么继续卖铲子"**——也就是去教别人赚钱。这路不是不能走，但它和你最初想"做点自己的小生意"完全是两码事。

这个系统**硬剔除卖铲子的人**。它只推一类人：

- 靠**真实的产品和服务**活下来的一人公司；
- 做内容 / 自媒体拿品牌合作、卖自己的信息产品、做付费社群、做产品化服务 / 代运营的实干派；
- 一句话：**自己下场干活赚钱的人，不是教别人赚钱的人。**

前者能模仿（你照着他的获客和变现路径做就行），后者模仿了也是去卖课。这，就是这份情报和别家最大的不同。

## 它会自己"长大"：越推越准、越推越广

普通情报系统是死的——你喂什么，它吐什么，永远就那点料。

这个系统会**自己找水源**：

- 每次推送，它都顺手去**发现一批新的内容源**（新的公众号、新的博主、新的 RSS）；
- 这些新源会被收进名单，之后持续追更；
- 你每收到一次推送，它的"情报网"就比前一天大一圈。

今天可能挖到 10 个案例，跑一个月，它的水源已经比刚开始丰富了好几倍。**它不是在重复旧内容，是在不断长出新案例。**

## 每天推给你什么

系统分两个模块，各推一张飞书卡：

| 模块 | 每天产出 | 说人话 |
|------|----------|--------|
| 🔍 **操盘手拆解** | 1–2 人 | 把一个"闷声赚钱的个体户"的生意拆开：做什么、客户从哪来、具体怎么操作 |
| 💡 **赚钱机会挖掘** | 约 10 条（国内 5 + 国际 5） | 用「四维度 + 三否决」筛出能复刻的真机会，**凡是卖铲子的一律不要** |

## 内容从哪来

- **国内**：微信公众号（按号名定向监测更新）、B站、小宇宙、中文搜索、精选中文 RSS
- **国际**：Starter Story / Side Hustle Nation / Indie Hackers 等 RSS，以及 Reddit、Twitter、YouTube
- **侦察兵**：每天自动挖新的「写一人公司 / 本身是 OPC」的号，列入名单持续追更（这就是它"长大"的方式）

### 🅱️ 路线 B：想自己部署（技术向，可选）

仓库自带完整代码，能跑在 GitHub Actions 上，完全免费。步骤：

```bash
git clone https://github.com/wsjxphz-png/opc-gold-daily.git
cd opc-gold-daily
python -m venv .venv && .venv/Scripts/activate   # Windows；mac/Linux 用 source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                              # 填入 FEISHU_WEBHOOK_URL 与 AI_API_KEY
python main.py --once                             # 立即跑一次（真实采集 + AI + 推飞书）
```

也可推到 GitHub 后用 Actions 定时运行（见 `.github/workflows/daily-push.yml`，默认北京时间每天 22:00）。**所有密钥走环境变量 / Secrets，绝不写进代码。**
